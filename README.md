# Snake

The classic Snake game in the browser. Eat the apple, grow, and do not hit the walls or yourself.

**Live:** https://snake-by-ivan-kuper.netlify.app

## Controls
`W` up, `A` left, `S` down, `D` right, or the arrow keys. On a phone, swipe on the board or tap the keys under it. The game waits for your first key; your best score is saved in the browser.

## Built with
HTML, CSS and plain JavaScript.

## Run locally
Open `index.html` in a browser.
